## Maintainer notes

This entry was written from Sisa Solutions' public repository rather than
submitted by them, and nobody there has confirmed it. The evidence is the
sisa-messaging-iggy crate (crates/iggy, on the `iggy` 0.12.0 client) and the
README's transport table, which lists Apache Iggy as experimental in 0.1.0, in
[sisaio/sisa-messaging-rs](https://github.com/sisaio/sisa-messaging-rs), read
2026-11-20. The crate is not on crates.io yet.

The website is left out: the organisation's GitHub profile gives sisa.io, but
that domain did not resolve on 2026-11-20. No logo: the organisation's GitHub
avatar is a generated identicon, not a mark.
