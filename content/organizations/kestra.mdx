## Maintainer notes

This entry was written from Kestra's public repository rather than submitted
by them, and nobody there has confirmed it. The evidence is
[kestra-io/plugin-iggy](https://github.com/kestra-io/plugin-iggy), released as
v1.0.0 on 2026-10-19, which depends on the Java SDK (org.apache.iggy:iggy
0.8.0) and provides Produce and Consume tasks, a polling Trigger and a
RealtimeTrigger. Read 2026-10-22.

The logos are taken from the organisation's own public materials:
src/assets/logo-black.svg and src/assets/logo-white.svg in
[kestra-io/docs](https://github.com/kestra-io/docs), the source of kestra.io.
