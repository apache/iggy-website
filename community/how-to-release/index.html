How to Release

Apache releases are source releases voted on by the project community. This page gives release managers a high-level checklist for Apache Iggy.

Release Checklist

  1. Prepare the release candidate from a clean source state and update versioned metadata.
  2. Build source artifacts, checksums and OpenPGP signatures.
  3. Verify licenses, NOTICE files, dependency metadata and source-only release contents.
  4. Call a vote on the dev mailing list and allow the required voting period.
  5. After approval, publish artifacts to Apache distribution infrastructure and update the website.
  6. Announce the release only after mirrors and public metadata have settled.

Required Reading

  • Apache Incubator release management
  • ASF release policy
  • ASF release distribution

Because Apache Iggy is incubating, release managers should make sure the release follows both project practice and Apache Incubator policy.
